# Кривые частота — ток нейронов (Allen Cell Types; IDEAS §18, задача 4)

## Цель (пользователь, 22.10.2026)
Найти новое и полезное, а не проверить NAI как на бенчмарке: перебирать постановки и параметры
программы на рабочей части; тест — один раз, после регистрации.

Вопрос: ложатся ли кривые f(I) тысяч реальных клеток на одну общую кривую в безразмерных переменных,
и какова её форма. Полезность: по порогу I_th и постоянной времени мембраны τ (дешёвые измерения)
предсказать всю кривую клетки — меньше опытов, параметры для моделей сетей.

## Проверка новизны (22.10.2026)
- Allen описывает кривую одним числом — наклоном прямой (`ef__f_i_curve_slope`).
- Вблизи порога кривая — степенной закон (Hansel & van Vreeswijk 2002; Roxin и др., J. Neurosci. 2011,
  «On the distribution of firing rates…»). Модель LIF: f = 1/(t_ref + τ·ln(x/(x − 1))), x = I/I_th.
- Подгонок нелинейных форм к данным Allen по всем типам клеток и проверки коллапса f·τ = G(I/I_th) на
  реальных клетках поиск не нашёл (препринт 2024 подгонял функции φ(V) к данным Allen, вид не уточнён).

## Данные
API Allen (`bench/allen_fi.py fetch`, 22.10.2026, `D:/Claude/nai-data/allen_ct`): 2 333 клетки (мышь 1 344 и
человек 289 в рабочей части), 58 585 прогонов Long Square (ток, длительность 1 с, число спайков). Строка —
клетка и ток не ниже реобазы (`ef__threshold_i_long_square`) со спайками; f — спайки/с, среднее по повторам.
Тест — 30 % клеток (700, зерно 20261022); рабочая часть — 1 633. Разведка — внутренние деления рабочей
части (зерно 1 или 2, проверка на 30 % клеток).

## Первые наблюдения (рабочая часть)
- У большинства клеток 6–10 точек выше порога; кривые чаще вогнутые (насыщение): 956 против 344 выпуклых
  и 260 почти прямых (клетки с ≥ 5 точками).
- **Коллапс по τ подтверждается:** в степенном законе lg f = a + b·lg(x − 1 + 0,05) + c·lg τ подогнанный
  показатель c = −1,09 и −1,05 (деления 1 и 2) — частота почти точно обратно пропорциональна τ.
- Форма LIF не подходит (0,74 dex против 0,33 у степенного с τ); класс клетки (шипиковая/нет), вид и
  входное сопротивление базовой модели почти ничего не добавляют.
- Ошибки велики у порога (x < 1,5: 0,39–0,45 dex): при реобазе частота почти всегда 1 Гц (один спайк).

## Разведка NAI (22.10.2026, рабочая часть)
**Постановка 1 — одна таблица всех клеток** (x, τ, [Ri, класс] → lg f, единая σ = 0,5 dex): NAI v21
объявляет «решено» формулам вроде lg f = x − 1 + (273 − 270√x + 164·ln x)/τ — при σ = 0,5 dex в «пределы
шума» проходит почти любая формула; при x ≥ 3 ошибка 0,9–1,5 dex. Разброс здесь — индивидуальность клеток,
а не шум измерения: такая постановка для поиска формы негодна.

**Постановка 2 — форма кривой:** режим групп, группа = клетка (одна форма, числа по клеткам), шум —
счётный (σ(lg f) = 1/(ln 10·√n)); NAI ищет по 60 клеткам, форма выбирается по наибольшим токам каждой клетки
(`--extrap x`). Проверка: у ~400 клеток проверки числа формы подгоняются по нижним 60 % токов, верхние
40 % предсказываются (продолжение кривой — экономия прогонов). Ошибка |lg(f̂/f)|, деление 1 / деление 2:

| модель | среднее | медиана |
|---|---|---|
| прямая по клетке, f = a + b·x | 0,147 / 0,139 | 0,074 / 0,078 |
| корень, f = a + b·√(x − 1) | 0,194 / 0,184 | 0,110 / 0,110 |
| степенной закон в lg | 0,228 / 0,219 | 0,122 / 0,142 |
| NAI, lg f, без ограничения констант | 0,198 / 0,273 | 0,110 / 0,132 |

Форма NAI (деление 1): lg f = a − b·exp(exp(c/x)) — подход к насыщению; кривые же у верхних токов растут
дальше, и прямая продолжает их лучше.
